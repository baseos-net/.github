# BaseOS Connect

**Connect your website to BaseOS.**

BaseOS Connect is the integration ecosystem that enables websites, CMS platforms, and custom applications to communicate with BaseOS through a shared protocol.

## What we build

- **Connect Protocol** — A unified integration contract.
- **Connect API** — The central integration interface provided by BaseOS.
- **Connect Laravel** — Laravel integration package.
- **Connect Node** — Node.js SDK and framework integrations.
- **Connect CLI** — Command-line tools for pairing, diagnostics, and synchronization.

## Architecture

All integrations share the same protocol, authentication model, pairing mechanism, site identity, and capability definitions.

BaseOS Core remains the central system for content workflows, synchronization, and data management.
